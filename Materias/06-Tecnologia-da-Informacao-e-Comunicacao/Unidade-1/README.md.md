## Introdução à disciplina

A disciplina de Tecnologia da Informação e da Comunicação (TIC) estuda como a tecnologia é utilizada para coletar, processar, armazenar, transmitir e proteger informações. Ela envolve desde os computadores e redes até sistemas inteligentes, bancos de dados e tecnologias emergentes como Inteligência Artificial e Internet das Coisas.

**Os principais temas da disciplina são:**
- Conceitos básicos de TIC
- Infraestrutura tecnológica
- Sistemas de informação
- Tecnologias de suporte à decisão
- Tecnologias emergentes
- Tendências tecnológicas
- Ferramentas de produtividade

## Conceito de tecnologia e de TIC

### O que é tecnologia?
Tecnologia é o conjunto de técnicas, ferramentas, métodos, processos e conhecimentos utilizados para resolver problemas e ampliar as capacidades humanas.

**Exemplos:**
- Um martelo é tecnologia.
- Um automóvel é tecnologia.
- Um computador também é tecnologia.

Ou seja, tecnologia não significa apenas informática.

### O que é TIC (Tecnologia da Informação e Comunicação)?
A TIC é uma área específica da tecnologia voltada para processamento de informações, comunicação de dados, armazenamento, transmissão e gerenciamento digital.

**Ela engloba:**
- Hardware
- Software
- Redes de computadores
- Bancos de dados
- Serviços digitais

## TIC dentro das organizações
Nas empresas, a TI funciona como um setor estratégico, assim como RH, Financeiro, Produção e Marketing. Hoje praticamente toda empresa depende de TIC para:
- controlar vendas,
- gerenciar clientes,
- armazenar dados,
- automatizar tarefas,
- analisar resultados,
- comunicar equipes.

## Evolução da tecnologia na sociedade
A evolução tecnológica aconteceu ao longo da história humana. Diversos fatores aceleraram esse avanço: guerras, necessidades econômicas, produção industrial, medicina, comunicação e educação. Cada avanço tecnológico transformou profundamente a sociedade.

## Revoluções Industriais
As Revoluções Industriais representam grandes mudanças nos modelos de produção.

### 1ª Revolução Industrial
- **Características:** Máquinas mecânicas, energia a vapor, uso da água como força motriz.
- **Impacto:** A produção manual começou a ser substituída por máquinas.

### 2ª Revolução Industrial
- **Características:** Eletricidade, produção em massa, linhas de montagem.
- **Impacto:** A fabricação ficou muito mais rápida e barata. (Exemplo: Ford e a produção em série).

### 3ª Revolução Industrial (Revolução Digital)
- **Características:** Computadores, robótica, eletrônica, CLPs (Controladores Lógicos Programáveis).
- **Impacto:** A automação industrial cresceu enormemente; as máquinas começaram a executar tarefas automaticamente.

### 4ª Revolução Industrial — Indústria 4.0 (Atual)
- **Características:** Sistemas inteligentes, comunicação entre máquinas, Internet das Coisas (IoT), Inteligência Artificial, Computação em Nuvem, Big Data.
- **Objetivo:** Criar fábricas inteligentes e altamente automatizadas.

## Indústria 4.0
A Indústria 4.0 integra computadores, sensores, internet, dispositivos móveis e máquinas industriais, tudo conectado em tempo real. Isso permite:
- monitoramento remoto,
- automação avançada,
- tomada de decisão automática,
- aumento da eficiência produtiva.

## Elementos da Indústria 4.0

### Elementos fundamentais
- **Internet das Coisas (IoT):** Objetos conectados à internet trocando informações (ex: relógios inteligentes, sensores industriais).
- **Sistemas Ciberfísicos (CPS):** Integram software, sensores e componentes físicos para monitorar e controlar processos automaticamente.
- **Internet de Serviços (IoS):** Serviços disponibilizados via internet (ex: streaming, cloud computing).

### Elementos estruturantes
- **Automação:** Máquinas executam tarefas automaticamente.
- **Comunicação Máquina a Máquina (M2M):** Máquinas trocam dados sem intervenção humana.
- **Inteligência Artificial (IA):** Sistemas capazes de aprender, analisar dados e tomar decisões.
- **Big Data:** Análise de grandes volumes de dados para prever tendências e otimizar processos.
- **Computação em Nuvem:** Armazenamento e processamento pela internet (ex: Google Drive, AWS).
- **Integração de Sistemas:** Diversos sistemas trabalhando juntos (ex: vendas integrado ao estoque).
- **Segurança Cibernética:** Proteção contra ataques, invasões e vazamento de dados.

### Elementos complementares
- **RFID:** Etiquetas eletrônicas usadas para rastreamento (logística, pedágios).
- **Realidade Virtual (RV):** Criação de ambientes totalmente virtuais.
- **Realidade Aumentada (RA):** Mistura elementos virtuais com o mundo real (ex: Pokémon GO).
- **QR Code:** Código visual que armazena informações digitais.
- **Manufatura Aditiva:** Impressão 3D, produção feita camada por camada.

## Evolução da computação
- **Ábaco:** Primeiro instrumento de cálculo conhecido (2500 a.C.).
- **Pascalina:** Criada por Blaise Pascal em 1642; calculadora mecânica.
- **Charles Babbage:** Criou a Máquina Diferencial e a Máquina Analítica (precursora do computador moderno com memória e processamento).

## Gerações dos computadores
1. **Primeira geração (1945–1955):** Válvulas eletrônicas. Enormes, lentos e alto consumo (Ex: ENIAC).
2. **Segunda geração (1955–1965):** Transistores. Menores, mais velozes e confiáveis (Ex: PDP-I).
3. **Terceira geração (1965–1980):** Circuitos integrados. Menores, rápidos e baratos (Ex: IBM System/360).
4. **Quarta geração (1980–atualidade):** Microprocessadores. Computadores pessoais, notebooks, smartphones (Ex: IBM-PC, Macintosh).

## Hardware e Software
- **Hardware:** Parte física (teclado, monitor, memória, processador, HD).
- **Software:** Parte lógica; programas executados (Windows, Linux, Word, navegadores).

## Redes de computadores
Permitem comunicação entre dispositivos para compartilhar dados, acessar internet e recursos (Wi-Fi, redes corporativas).

## Banco de dados
Sistema organizado para armazenar informações (clientes, estoque, bancos), permitindo armazenamento eficiente, consultas rápidas e segurança.

## Resumo geral
- **TIC envolve:** hardware, software, redes, bancos de dados e comunicação digital.
- **Revoluções industriais:** Do vapor à inteligência conectada (Indústria 4.0).
- **Tecnologias atuais:** IA, IoT, Big Data, Cloud Computing e Cibersegurança.
- **Conceitos fundamentais:** Hardware (físico), Software (lógico), Redes (comunicação) e Banco de dados (armazenamento).

# Evolução da TI nas Organizações + Dados, Informação e Conhecimento

Agora vamos entrar em uma parte MUITO importante da disciplina: entender como a Tecnologia da Informação evoluiu dentro das empresas e como os conceitos de **dados, informação e conhecimento** se conectam.

# Evolução da TI nas organizações

A evolução da TI nas empresas aconteceu gradualmente.

No começo, os computadores eram extremamente caros, grandes e difíceis de operar. Com o tempo, a tecnologia foi ficando:

* menor,
* mais rápida,
* mais acessível,
* mais conectada,
* e mais estratégica.

Vamos entender década por década.

# Década de 1960 — O início da TI empresarial

## Mainframes

Nessa época surgem os **mainframes**, computadores gigantes usados por grandes empresas.

Empresas como:

* IBM
* Honeywell
* NCR
* GE

dominavam esse mercado.

Os mainframes ocupavam salas inteiras e tinham enorme poder de processamento para a época.

## Centros de Processamento de Dados (CPDs)

As empresas começaram a criar os chamados:

# CPDs — Centros de Processamento de Dados

Eram setores especializados onde ficavam:

* os computadores,
* operadores,
* fitas magnéticas,
* armazenamento de dados.

Tudo era extremamente centralizado.

## Características da TI nessa época

### Pouca mão de obra especializada

Havia poucos profissionais capazes de operar os sistemas.

Programar era algo extremamente técnico e complexo.

### Custos altíssimos

A tecnologia era muito cara:

* equipamentos,
* manutenção,
* energia,
* treinamento.

Somente grandes empresas conseguiam investir nisso.

### Foco maior na tecnologia do que nos processos

As empresas ainda não entendiam bem como usar TI estrategicamente.

O foco era:

> “ter o computador funcionando”.

Ainda não existia preocupação forte com:

* gestão,
* produtividade,
* integração,
* estratégia.

# Década de 1970 — Surgimento dos sistemas de informação

Aqui começa uma mudança importante.

A TI deixa de ser apenas processamento e começa a apoiar a gestão das empresas.

## Primeiros sistemas de informação modernos

Surgem sistemas capazes de:

* organizar dados,
* gerar relatórios,
* apoiar decisões.

As empresas começam a perceber valor nos dados.

## Surgimento dos computadores pessoais

Os PCs começam a aparecer.

Ainda eram limitados, mas revolucionários.

Isso iniciou a descentralização do acesso à computação.

## Bancos de dados modernos

Começam a surgir sistemas de banco de dados mais estruturados.

Isso permitiu:

* armazenar grandes quantidades de informações,
* consultar dados rapidamente,
* organizar registros de clientes, estoque, vendas etc.

## Crescimento da TI nas empresas

A TI começa a ganhar importância organizacional.

Porém ainda existiam problemas:

* pouca metodologia,
* administração deficiente,
* gerenciamento desorganizado.

# Década de 1980 — Expansão dos PCs e redes

Essa década marca a popularização da computação.

# Computadores pessoais em larga escala

# Crescimento das redes de computadores

As máquinas começam a se conectar.

Isso permitiu:

# Formação da internet

A internet ainda estava começando, mas já ganhava estrutura.

# Boas práticas começam a surgir

As empresas começam a perceber a necessidade de:

# Surgimento da terceirização

# Dados

Agora entramos em um conceito ESSENCIAL.

# O que são dados?

Dados são:

# fatos brutos e isolados.

Eles ainda não possuem interpretação completa.

Exemplos:

* número de funcionários,
* quantidade em estoque,
* horas trabalhadas,
* valor de uma venda.

Sozinhos, os dados dizem pouca coisa.

# Tipos de dados

## Dados alfanuméricos

* letras,
* números,
* caracteres.

Exemplo:

* CPF,
* nome,
* código de produto.

## Dados em áudio

* sons,
* músicas,
* gravações.

## Dados de imagem

* fotos,
* gráficos,
* figuras.

## Dados de vídeo

* imagens em movimento.

# Informação

Quando organizamos os dados e damos significado a eles, surge a informação.

# O que é informação?

Informação é:

# dado interpretado e contextualizado.

Ela possui significado e utilidade.

## Exemplo simples

### Dado:

* “150”

Sozinho isso não significa muita coisa.

### Informação:

* “Foram vendidos 150 produtos hoje.”

Agora existe contexto e significado.

# Analogia do quebra-cabeça

O slide usa uma analogia muito boa:

* cada peça separada = dado
* quebra-cabeça montado = informação

Ou seja:

> a organização dos dados gera informação.

# Conhecimento

O conhecimento é o próximo nível.

# O que é conhecimento?

Conhecimento é:

# compreensão da informação + capacidade de utilizá-la.

Envolve:

* interpretação,
* experiência,
* contexto,
* tomada de decisão.

## Exemplo completo

### Dado:

* “150 vendas”

### Informação:

* “As vendas aumentaram 30% este mês.”

### Conhecimento:

* “A campanha de marketing funcionou e devemos investir mais nela.”

Perceba:

* dado = fato bruto
* informação = fato organizado
* conhecimento = entendimento aplicado

# Relação entre dado, informação e conhecimento

## Dado

É objetivo e bruto.

↓

## Informação

Dado com contexto e significado.

↓

## Conhecimento

Informação interpretada e utilizada para decisões.

# Evolução da TI nas organizações

Agora começamos a entrar na forma como a Tecnologia da Informação evoluiu dentro das empresas. Esse tema é muito importante porque mostra como a TI deixou de ser apenas “máquinas e suporte técnico” para se tornar algo estratégico para os negócios.

# Décadas iniciais da TI nas empresas

## Chegada dos mainframes

Os **mainframes** foram os primeiros computadores de grande porte utilizados pelas empresas.

Eles eram:

* enormes;
* extremamente caros;
* muito poderosos para a época;
* utilizados principalmente por grandes organizações e governos.

Esses computadores centralizavam praticamente todo o processamento da empresa.

## Exemplo:

Um banco utilizava um único mainframe para:

* armazenar contas;
* processar transações;
* controlar clientes;
* emitir relatórios.

Os usuários acessavam esse computador por terminais simples chamados de “terminais burros”, que praticamente não possuíam processamento próprio.

# Centros de Processamento de Dados (CPDs)

Com os mainframes surgiram os **CPDs — Centros de Processamento de Dados**.

Eram ambientes especializados criados para:

* armazenar computadores;
* controlar processamento;
* manter sistemas funcionando;
* proteger equipamentos.

Esses locais possuíam:

* refrigeração especial;
* controle de energia;
* segurança física;
* equipes técnicas.

Na prática, o CPD era o “coração tecnológico” da empresa.

# Falta de mão de obra especializada

Naquela época havia poucos profissionais qualificados em TI.

Isso acontecia porque:

* a computação ainda era nova;
* poucas universidades ensinavam tecnologia;
* os equipamentos eram complexos;
* o conhecimento técnico era restrito.

Consequentemente:

* os salários eram altos;
* a manutenção era difícil;
* os sistemas demoravam para ser desenvolvidos.

# Computação centralizada

Inicialmente toda a computação era centralizada.

Ou seja:

* um único computador fazia todo o processamento;
* os usuários apenas enviavam comandos.

Esse modelo tinha vantagens:

* maior controle;
* centralização de dados;
* segurança.

Mas também possuía problemas:

* pouca flexibilidade;
* dependência total do computador central;
* custos muito altos.

# Arquitetura cliente-servidor

Com o avanço tecnológico, surgiu o modelo cliente-servidor.

Nesse modelo:

* o servidor fornece recursos e dados;
* o cliente (computador do usuário) também realiza processamento.

## Exemplo:

Hoje:

* seu notebook é o cliente;
* o servidor pode ser um site, banco ou sistema na nuvem.

Isso descentralizou a computação e aumentou:

* desempenho;
* flexibilidade;
* escalabilidade.

# Poucas soluções tecnológicas e altos custos

Nas décadas iniciais:

* existiam poucos softwares;
* o hardware era caríssimo;
* manutenção custava muito;
* apenas grandes empresas conseguiam investir.

A TI era considerada um luxo corporativo.

Hoje ocorreu o contrário:

* computadores são baratos;
* softwares são abundantes;
* existem serviços em nuvem;
* pequenas empresas também utilizam TI.

# Critérios de qualidade da informação

Nem toda informação é útil. Para ser valiosa, ela precisa possuir qualidade.

Esses critérios ajudam empresas a garantir que a informação realmente possa apoiar decisões.

# Efetividade

A informação precisa:

* ser importante;
* chegar no momento correto;
* ser útil ao negócio.

## Exemplo:

Um relatório financeiro entregue depois da reunião perde efetividade.

# Eficiência

Relaciona-se ao uso inteligente de recursos.

A informação deve ser produzida:

* rapidamente;
* com menor custo possível;
* sem desperdícios.

# Confidencialidade

Refere-se à proteção da informação contra acessos indevidos.

## Exemplo:

* senhas;
* dados bancários;
* prontuários médicos.

Somente pessoas autorizadas devem acessar essas informações.

# Integridade

A informação precisa estar:

* correta;
* completa;
* sem alterações indevidas.

## Exemplo:

Se um sistema altera valores financeiros incorretamente, a integridade foi comprometida.

# Disponibilidade

A informação deve estar acessível quando necessária.

Não adianta um sistema ser seguro se ele nunca funciona.

## Exemplo:

Um site bancário fora do ar compromete a disponibilidade.

# Conformidade

Relaciona-se ao cumprimento de:

* leis;
* regulamentos;
* normas;
* políticas internas.

## Exemplo:

No Brasil temos a LGPD, que regula proteção de dados pessoais.

# Confiabilidade

A empresa precisa confiar nas informações geradas.

Informações incorretas geram:

* decisões erradas;
* prejuízos;
* falhas estratégicas.

# Características da informação valiosa

Uma informação de qualidade possui várias características importantes.

# Acessível

Deve poder ser obtida facilmente pelas pessoas autorizadas.

# Precisa

Precisa estar correta.

# Completa

Não pode faltar partes importantes.

# Econômica

O custo para obter a informação deve valer o benefício.

# Flexível

Deve servir para diferentes finalidades.

# Relevante

Precisa ser importante para quem a utiliza.

# Confiável

Deve transmitir segurança e credibilidade.

# Segura

Protegida contra perdas e invasões.

# Simples

Informações muito complexas dificultam decisões.

# Atualizada

Informações antigas podem perder valor.

# Verificável

Deve ser possível confirmar sua veracidade.

Até aqui você já viu que a infraestrutura de TI é a base tecnológica que sustenta os sistemas e operações das empresas.

* Hardware;
* Software;
* Banco de dados;
* Redes de computadores;

Esses elementos trabalham juntos o tempo inteiro.

# Hardware

O hardware é a parte física do sistema computacional.

Tudo aquilo que pode ser tocado é hardware.

## Exemplos:

* teclado;
* mouse;
* monitor;
* placa-mãe;
* processador;
* HD;
* SSD;
* impressora;
* roteador.

O hardware é responsável por:

* processamento;
* armazenamento;
* entrada de dados;
* saída de informações.

Mas o hardware sozinho não “faz nada”.

Ele precisa do software para funcionar.

# Software

O software é a parte lógica do computador.

Ele é formado por conjuntos de instruções e programas que dizem ao hardware o que deve ser feito.

## Resumindo:

* Hardware = parte física;
* Software = parte lógica.

Sem software:

* o computador não executa tarefas;
* os componentes físicos ficam inutilizados.

# Como hardware e software trabalham juntos

Imagine um teclado:

* o hardware é o teclado físico;
* o software interpreta a tecla pressionada.

Quando você abre um navegador:

* o processador executa operações físicas;
* o software organiza essas operações.

O computador funciona justamente da integração entre os dois.

# Classificação dos softwares

Os softwares podem ser divididos em duas grandes categorias:

* software de sistema;
* software de aplicação.

# Softwares de sistema

Também chamados de softwares básicos.

São responsáveis por:

* controlar o hardware;
* administrar recursos do computador;
* servir de ponte entre hardware e aplicativos.

O principal exemplo é o sistema operacional.

# Sistema operacional

O sistema operacional coordena o funcionamento do computador.

Ele controla:

* memória;
* processador;
* armazenamento;
* entrada e saída;
* execução de programas.

## Exemplos:

* Windows;
* Linux;
* macOS;
* Android;
* iOS.

# Funções do software de sistema

## Gerenciar hardware

Controla os dispositivos físicos.

## Gerenciar processos

Organiza programas em execução.

## Gerenciar memória

Distribui memória para os programas.

## Gerenciar arquivos

Controla armazenamento e acesso aos dados.

## Permitir interação do usuário

Oferece interface gráfica ou terminal.

# Softwares de aplicação

São programas criados para atender necessidades específicas dos usuários.

Eles ajudam pessoas e empresas em tarefas do dia a dia.

# Exemplos de softwares de aplicação

* Word;
* Excel;
* PowerPoint;
* navegadores;
* sistemas empresariais;
* aplicativos bancários;
* editores de imagem.

# Diferença entre software de sistema e software de aplicação

| Software de Sistema                 | Software de Aplicação          |
| ----------------------------------- | ------------------------------ |
| Controla o computador               | Resolve tarefas do usuário     |
| Gerencia hardware                   | Executa atividades específicas |
| Serve de base para outros programas | Depende do sistema operacional |
| Exemplo: Windows                    | Exemplo: Word                  |

# Relação entre os dois

O software de aplicação depende do software de sistema.

## Exemplo:

O Word não conversa diretamente com o hardware.

Ele utiliza o Windows para:

* acessar memória;
* salvar arquivos;
* imprimir documentos.

O sistema operacional funciona como intermediário.

# Principais fatores de avaliação de software

Quando uma empresa escolhe um software, ela analisa vários critérios importantes.

# Eficiência

O software deve:

* consumir poucos recursos;
* utilizar bem memória e processamento;
* funcionar rapidamente.

# Flexibilidade

O sistema deve se adaptar facilmente a novas necessidades.

## Exemplo:

Uma empresa cresce e o software precisa suportar novos usuários.

# Segurança

O software deve proteger:

* dados;
* usuários;
* operações.

Também precisa evitar:

* falhas;
* invasões;
* acessos indevidos.

# Conectividade

O software precisa conseguir se comunicar com:

* internet;
* redes;
* outros sistemas.

Hoje praticamente todos os sistemas precisam ser conectados.

# Linguagem de programação

Empresas avaliam:

* se a linguagem utilizada é moderna;
* se há profissionais disponíveis;
* se a manutenção será fácil.

# Documentação

Um software bem documentado facilita:

* aprendizado;
* suporte;
* manutenção;
* desenvolvimento futuro.

# Compatibilidade com hardware

O sistema precisa funcionar corretamente nos equipamentos disponíveis.

## Exemplo:

Um software pesado pode exigir:

* mais memória RAM;
* processadores modernos;
* placas gráficas específicas.

# Outros fatores importantes

Também são analisados:

* custo;
* desempenho;
* confiabilidade;
* disponibilidade;
* suporte técnico;
* ergonomia;
* modularidade;
* adaptabilidade.

# Computador

O computador é um sistema programável composto por:

* hardware;
* software.

Ele recebe dados, processa informações e produz resultados.

# Funcionamento básico do computador

O ciclo básico ocorre assim:

1. Entrada de dados;
2. Processamento;
3. Armazenamento;
4. Saída de informações.

# Principais tipos de computadores

# Mainframes

Computadores gigantes utilizados por:

* bancos;
* governos;
* grandes empresas.

São extremamente poderosos.

# Supercomputadores

Utilizados para cálculos extremamente complexos.

## Exemplos:

* previsões climáticas;
* pesquisas científicas;
* inteligência artificial;
* simulações espaciais.

# Servidores

Fornecem serviços para outros computadores.

## Exemplos:

* hospedagem de sites;
* armazenamento de arquivos;
* bancos de dados.

# Desktops

Computadores de mesa tradicionais.

# Computadores portáteis

* notebooks;
* tablets;
* smartphones.

# Banco de dados (BD)

O banco de dados é um sistema organizado de armazenamento de informações.

Ele permite:

* armazenar;
* organizar;
* consultar;
* atualizar dados.

# Exemplos de dados armazenados

* clientes;
* produtos;
* vendas;
* funcionários;
* contas bancárias.

# Sistema Gerenciador de Banco de Dados (SGBD)

O SGBD é o software responsável por controlar o banco de dados.

Ele faz:

* criação;
* organização;
* acesso;
* segurança;
* manipulação dos dados.

# Exemplos de SGBDs

* MySQL;
* PostgreSQL;
* Oracle;
* SQL Server;
* MongoDB.

# Relação entre aplicação, SGBD e banco de dados

O funcionamento geralmente ocorre assim:

Aplicação → SGBD → Banco de Dados

## Exemplo:

Um aplicativo bancário:

* envia solicitações;
* o SGBD processa;
* os dados são acessados no banco.

# Benefícios dos bancos de dados

# Redução da redundância

Evita duplicação desnecessária de dados.

# Integridade dos dados

Garante consistência e confiabilidade.

# Facilidade de atualização

Permite modificar informações rapidamente.

# Compartilhamento de dados

Vários usuários podem acessar os mesmos dados simultaneamente.

# Segurança

Controle de acesso e proteção das informações.

# Independência dos programas

Os dados ficam separados das aplicações.

Isso facilita mudanças nos sistemas.

# Melhor tomada de decisão

Dados organizados geram informações valiosas para gestores.

# Dados e tomada de decisão

Os dados são fundamentais para decisões empresariais.

Sem dados:

* não existe análise;
* não existe planejamento;
* não existe estratégia eficiente.
