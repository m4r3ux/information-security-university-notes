# 1. O que são planilhas eletrônicas?

As planilhas eletrônicas são programas utilizados para:

- Organizar dados;
    
- Realizar cálculos;
    
- Criar relatórios;
    
- Gerar gráficos;
    
- Apoiar a tomada de decisão.
    

A informação é organizada em uma estrutura de:

- **Linhas** (horizontais)
    
- **Colunas** (verticais)
    
- **Células** (interseção entre linha e coluna)
    

Exemplo:

|A|B|
|---|---|
|Produto|Preço|
|Notebook|3500|
|Mouse|80|

A célula que contém "Notebook" é **A2**.

### Evolução

|Ano|Software|
|---|---|

|1985|Excel (Microsoft)|

### Importância

O surgimento das planilhas mostrou que os computadores poderiam ser utilizados para:

- Controle financeiro;
    
- Gestão empresarial;
    
- Análise de dados;
    
- Planejamento.
    

Hoje o Excel é uma das ferramentas mais utilizadas no mundo corporativo.

# 3. O que é o Excel?

O Excel é um software da Microsoft destinado à criação e gerenciamento de planilhas eletrônicas.

Características:

- Organiza dados em células;
    
- Executa cálculos automaticamente;
    
- Cria gráficos;
    
- Permite análises estatísticas;
    
- Trabalha com várias planilhas dentro de um único arquivo.

# 5. Referências de células

As referências indicam quais células serão usadas no cálculo.

## Uma única célula

```text
H10
```

Significa:

- Coluna H
    
- Linha 10
    

---

## Intervalo vertical

```text
G1:G30
```

Vai de:

- G1 até G30
    

---

## Intervalo horizontal

```text
A7:I7
```

Vai de:

- A7 até I7
    

---

## Linha inteira

```text
1:1
```

Toda a linha 1.

---

## Várias linhas

```text
1:3
```

Linhas 1, 2 e 3.

---

## Coluna inteira

```text
J:J
```

Toda a coluna J.

---

## Duas colunas inteiras

```text
D:E
```

Colunas D e E.

---

## Bloco de células

```text
A6:F8
```

Todas as células do retângulo formado por:

- Colunas A até F
    
- Linhas 6 até 8

# 8. O que são funções?

Funções são fórmulas prontas criadas pelo Excel.

Estrutura:

```excel
=NOME_DA_FUNÇÃO(argumentos)
```

Exemplo:

```excel
=SOMA(A1:A10)
```

Onde:

- SOMA = função
    
- A1:A10 = argumentos

A disciplina destaca um ponto importante:

### Excel NÃO substitui sistemas de informação.

Embora seja muito poderoso, ele possui limitações:

- Erros de digitação;
    
- Fórmulas incorretas;
    
- Dados duplicados;
    
- Falhas humanas;
    
- Problemas de controle de versões.
    

Por isso, empresas grandes utilizam:

- ERPs;
    
- Bancos de dados;
    
- Sistemas corporativos.
    

E usam o Excel como ferramenta de apoio.

# 4. Outlook

## O que é?

O Outlook é um software utilizado para:

- Gerenciar e-mails
    
- Organizar compromissos
    
- Controlar tarefas
    
- Gerenciar contatos
    
- Utilizar calendário
    

Principal exemplo:

Microsoft Outlook

---

### E-mail

Permite:

- Enviar mensagens
    
- Receber mensagens
    
- Arquivar e-mails
    
- Organizar pastas
    
- Pesquisar mensagens
    

---

### Calendário

Permite:

- Agendar reuniões
